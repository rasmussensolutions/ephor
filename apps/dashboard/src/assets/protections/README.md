# Protection marks

- `crowdsec.png`: the unmodified official CrowdSec mark without text, fetched from https://raw.githubusercontent.com/crowdsecurity/crowdsec-docs/main/crowdsec-docs/static/img/crowdsec_no_txt.png. Used solely to identify the CrowdSec integration; CrowdSec retains its brand rights.
- Automatic updates uses the existing Simple Icons Debian and Ubuntu marks to identify supported distributions. These are distribution logos, not a claimed unattended-upgrades product logo. Upstream brand sources: https://www.debian.org/logos/ and https://design.ubuntu.com/brand.
